# PID Control

## Overview
A PID controller computes a control input from the error between a desired and measured value using proportional, integral, and derivative terms. It is the most widely used feedback controller in practice. In robotics it commonly controls motor speed and position, joint angles, and vehicle heading and speed, and it is often the first controller to try on a new system.
