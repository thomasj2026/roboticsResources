# David Silver's Reinforcement Learning Course

## Overview
Reinforcement learning trains an agent to choose actions that maximize long-term reward through trial and error, usually formalized as a Markov decision process. In robotics it is used to learn locomotion, manipulation, and control policies that are hard to hand-design, and it is widely used to train legged robots in simulation. This course explains the underlying principles before the deep learning methods built on them.
