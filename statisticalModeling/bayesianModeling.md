# Bayesian Modeling

## Overview
Bayesian modeling represents beliefs as probability distributions and updates them with Bayes' rule as new data arrive. Bayesian networks extend this to many variables by encoding their dependencies in a graph. In robotics this is the basis of probabilistic state estimation, sensor fusion, and mapping and localization, and it provides a principled way to handle uncertainty and to reason about it.
