# Markov Decision Processes

## Overview
A Markov decision process (MDP) models sequential decision making under uncertainty with states, actions, transition probabilities, and rewards, where the next state depends only on the current state and action. It is the standard framework for planning and reinforcement learning. In robotics it is used to model navigation, manipulation, and control problems in which actions have uncertain outcomes.
