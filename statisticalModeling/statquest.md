# StatQuest

## Overview
StatQuest is a YouTube channel that explains statistics and machine learning concepts step by step with simple visuals. It is useful for building intuition for the statistical methods used in robotics, such as probability, regression, and the machine learning techniques behind perception and learning-based control.
