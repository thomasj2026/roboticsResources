# System Identification

## Overview
System identification builds mathematical models of a system from measured input-output data instead of deriving them from first principles. In robotics it is used to estimate parameters such as mass, inertia, friction, and motor constants, and to get accurate models for simulation and for model-based controllers such as MPC.
