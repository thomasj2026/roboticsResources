# Tutorials

## Overview
Worked tutorials help connect control and robotics theory to practice by modeling and controlling a concrete system step by step. These cover classic control examples and a hands-on path toward building and navigating a simulated robot.

## Sources
- [Inverted pendulum: PID controller design (Control Tutorials for MATLAB and Simulink, University of Michigan)](https://ctms.engin.umich.edu/CTMS/index.php?example=InvertedPendulum&section=ControlPID): a tutorial that models the inverted pendulum dynamics and designs a PID controller for it.
- [Suspension: PID controller design (Control Tutorials for MATLAB and Simulink, University of Michigan)](https://ctms.engin.umich.edu/CTMS/index.php?example=Suspension&section=ControlPID): a tutorial that models a bus suspension system and designs a PID controller for it.
- [gazebo_autonomous_driving (lucasmazzetto, GitHub)](https://github.com/lucasmazzetto/gazebo_autonomous_driving/blob/main/README.md): a project README for autonomous driving in Gazebo. It is recommended to start by building your own differential-drive robot with a lidar and using Nav2 before attempting this one.
