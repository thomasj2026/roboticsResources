# Software

## Overview
Robotics projects depend on many Python packages with specific versions, and managing them with an environment manager keeps each project's dependencies isolated and reproducible. This matters for ROS 2 Python nodes, simulation, and machine learning work, where mismatched versions cause hard-to-debug failures.
